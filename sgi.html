Contexte du projet

Le projet SGI (Système de Gestion de l’Intendance) est une application web réalisée dans le cadre du BTS SIO option SLAM.

Cette application permet de centraliser et simplifier la gestion des demandes de matériel au sein d’un établissement scolaire.

Le projet a été développé en équipe avec Laravel en utilisant GitHub pour le travail collaboratif.

Fonctionnalités

  • Gestion des utilisateurs
  • Gestion des demandes
  • Suivi des informations
  • Interface administrateur
  • Base de données MySQL

Compétences développées

  • Développement Laravel
  • Programmation PHP
  • Travail en équipe
  • Gestion GitHub
  • Conception base de données

Mon rôle dans le projet

J’ai participé au développement backend, à la gestion des données et à plusieurs fonctionnalités de l’application.

Ce projet m’a permis d’améliorer mes compétences en développement web et en travail collaboratif.
